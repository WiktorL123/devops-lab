# Cost awareness skill

Default to the cheapest sensible lab option.

Before selecting a paid SKU:
- explain why the proposed SKU is enough,
- state what a production-oriented option would add,
- ask for approval.

Distinguish:
- compute cost,
- storage cost,
- networking cost,
- fixed/base fees,
- usage-driven fees,
- idle cost.

Azure promotional credit is dynamic.
The currently observed value is $175, but never assume it is still current when a decision depends on the balance.
