# CI/CD concepts skill

Model CI/CD in provider-neutral concepts first:
- trigger,
- job/stage,
- dependency,
- artifact,
- condition,
- environment,
- secret,
- runner/agent,
- quality gate,
- deployment gate.

Lab policy:
- separate frontend/backend CI,
- lint -> test -> build,
- PR CI,
- repeated post-merge CI,
- deploy only after successful post-merge CI,
- path-scoped execution.
